AI Virtual Assistant (AI Mini Alexa)

A Python-based virtual assistant built with Streamlit that supports text commands, voice input, and spoken responses.

Features

- Voice and text interaction
- Time and date updates
- Motivational quotes and AI facts
- Simple, user-friendly interface

Technologies

Python · Streamlit · Speech-to-Text · Text-to-Speech

Run the Project

python -m streamlit run app.py
